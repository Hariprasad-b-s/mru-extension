MRU Tab Switcher

Switch to the tab you used last, not the next one to the right.

Thanks for installing! It works right away with the shortcut below. Pin it from the puzzle-piece menu to see its ON/OFF badge; clicking the icon turns it on or off.

How it works

  • Press Alt+Y once to go to your previous tab, and again later to come back.
  • Press it again before you pause to keep going back: 2nd, 3rd, 4th most recent tab, and so on.
  • Alt+Shift+Y goes the other way through the same list; on its own it jumps to the tab you used least recently.
  • Want it exactly like Brave, where letting go of Ctrl ends the cycle? Turn on End the cycle when I let go of Ctrl below.

Use Ctrl+Tab and Ctrl+Shift+Tab

Chrome doesn't let extensions take Tab shortcuts, and its shortcuts page won't accept the Tab key, but you can set them once in under a minute:

  1. Click Copy setup code.
  2. Click Open shortcuts page, then open DevTools there: Ctrl+Shift+J (Windows/Linux) or Cmd+Option+J (macOS).
  3. Paste into the Console and press Enter. If Chrome asks, type allow pasting first, then paste again.

Settings Saved

Hold Ctrl and keep tapping Tab for as long as you like; letting go ends the cycle. To notice that, a tiny listener runs in web pages, so Chrome will ask to "Read and change all your data on all websites". It only notices Ctrl being released (or a click) while you switch tabs, and never reads or changes pages. Where extensions can't run (the New Tab page, chrome:// pages, the Chrome Web Store), the pause below is used instead.

Presses closer together than this keep going further back. Lower it if you tap quickly; raise it if you like to look at each tab. With "let go of Ctrl" on, this is only used on pages where the release can't be detected.

Every tab you land on while cycling counts as recently used, as in Brave. Turn off to count only the tab you stop on.

No overlays and no data collected; settings stay on your device. Page access only if you turn on "let go of Ctrl". Help · Privacy
